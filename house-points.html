🔧 One-time setup — connect your Google Sheet

1
Go to sheets.google.com and create a new spreadsheet. Name it Avyukth House Points. The first sheet should have these column headers in row 1: date  activity  note  timestamp
2
In your Google Sheet, go to Extensions → Apps Script. Delete any existing code and paste in the script from the google-apps-script.js file that came with this page. Click Save, then Deploy → New deployment. Choose type Web app, set "Execute as" to Me and "Who has access" to Anyone. Click Deploy and copy the Web App URL.
3
Paste the Web App URL below and click Save. That's it — House Points is ready!
